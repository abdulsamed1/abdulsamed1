## About

Software engineer interested in **backend Engineering**. My projects work explores how services handle concurrency, retries, external integrations, and invalid or incomplete input.

I value explicit contracts, validation at system boundaries, controlled failure handling, and clear separation between model decisions and deterministic application logic. I am currently interested in **Frontier Deployed Engineering** role.
